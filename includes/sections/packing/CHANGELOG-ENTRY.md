Added Packing section — which bag every fish goes in and which box an order fits in, so that packing no longer lives in one head. **Bags**: a list of the standard bags under FisHotel Tools → Packing (a name, an optional width and length in inches, a sort number; nothing is seeded; a bag keeps its id for good, so a rename changes nothing on the products that use it and a removed bag's id is never reused). **Bag size per fish**: an admin-only *Bag size* dropdown on every product variation and on simple products (Shipping tab) in the classic product editor, stored as the hidden meta `_fh_bag_size` (a bag id) through the product object behind `manage_woocommerce` and the section's own nonce — a record only: not an attribute, no variation, no term, never written to an order line, and the section registers no hook at all outside wp-admin, so it never appears on the storefront, in the cart, at checkout, in e-mails, on invoices, in My Account or in the customer-facing REST / Store API (a front-end request loads nothing but the section's own file, hooks nothing and reads no option). **Size → bag**: a table mapping each fish size to a bag — the sizes are the Clean Room's list when that section is switched on (`Sizes::standard()`, reached through `class_exists` / `method_exists`), else the terms of the product attribute whose name contains "size", found by this section; a variation's own value overrides the map, and the same map answers for fish that are not shop products (an invoice line, an unlisted fish) from the size on the line. *Fill empty ones from the map* previews how many variations it would set (and how many carry a size with no bag, or no size) and then sets, a batch at a time, only those that have no value — each checked once more just before it is written. **Boxes**: the standard boxes come from ShipTracker when the active build provides them (`FST_Settings::get_standard_boxes()`, guarded with `method_exists`) and otherwise from this section's own list (name, length, width, height in inches); the Boxes tab says which. For each box and each bag the owner types how many fit (blank = that bag does not go in that box); the numbers follow a box by its name, or by its size when it was renamed or moved to ShipTracker's list. **The suggestion** (a pure class): bags needed = each fish line's quantity in its bag size, one bag per fish (the filter `fishotel_packing_fish_per_bag` is the seam for more); the fill of a box = the sum over the bag sizes of bags needed ÷ how many fit; the smallest box by volume whose fill is at most 100 % is suggested; when none holds it all the order is split — the largest box filled first, bulkiest bags first, then the smallest box that holds the rest — and says so; a box at or over the threshold (a setting, 90 % by default) is flagged *on the line* for the owner to confirm; lines with no bag size are listed by name and the suggestion is marked incomplete; items that are not fish (the Ship Day pick list's rules, plus any product that carries a Bag size of its own) are ignored and named; a bag no box takes is set aside and named. **On the order**: a *Packing* box on the order screen, legacy and HPOS alike — each fish line with its bag and where it came from, the bags by size, the suggested box with its fill, the on-the-line flag, and a Confirm / change / clear control that stores the chosen box as order meta (`_fh_packing_box`, `_fh_packing_box_name`) through the order object, with `manage_woocommerce` and a nonce; no note, no e-mail, no status or stock change. A combined box is read through its live source orders, and an order that went into one points to it. **Contracts**: `fishotel_packing_suggest( $order_id )`, `fishotel_packing_bag_for_item( $order_item )` (for the pick list), `fishotel_packing_confirmed_box( $order_id )`, plus `fishotel_packing_bag_for_product()` and `fishotel_packing_bag_for_size()` — each with a filter of the same name, answering "nothing" while the section is off — and the actions `fishotel_packing_box_confirmed` / `fishotel_packing_box_cleared`. Storage is one option that is not autoloaded (`fishotel_packing_settings`): no table, no cron, no REST route.
