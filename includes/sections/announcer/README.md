# Announcer Section

Display notification bars, announcement banners, and promotional messages across your site.

## Features

- **Unlimited Announcements** — create multiple notification bars
- **Top / Bottom positioning** with sticky (fixed) option
- **Full-width or boxed layout**
- **Display triggers** — immediate, timed delay, or on scroll percentage
- **Scheduling** — start and end date/time
- **Close button** with cookie-based "remember closed" (session or X days)
- **CTA Buttons** — multiple per announcement, open link / close / both, per-button colors and 10 animations
- **Location Rules** — show/hide on specific pages, posts, categories, post types, archives, search, 404, URL contains
- **Visitor Conditions** — target by device, browser, OS, logged-in status, user role, referrer, language
- **Multiple Messages** — ticker/slider with auto-play and navigation, random mode, horizontal marquee scrolling
- **Countdown Timer** — customizable end date, label, and completion behavior
- **Shortcode** — `[fishotel_announcement id="123"]` for inline placement
- **One-Click Duplicate** — clone announcements from the list table
- **Show/Close Animations** — slide, fade, bounce, zoom
- **CTA Button Animations** — bounce, flash, pulse, shake, swing, tada, wobble, jello, heartbeat, rubber band
- **Smart Stacking** — multiple sticky bars adjust body padding automatically
- **100% Responsive** — mobile-first design
- **Rich Content** — HTML, images, shortcodes in announcement content

## Shortcode

```
[fishotel_announcement id="123"]
```

## Multiple Messages

Separate messages in the WordPress editor with `<!--message-->`:

```
First message content here
<!--message-->
Second message content here
<!--message-->
Third message content here
```
